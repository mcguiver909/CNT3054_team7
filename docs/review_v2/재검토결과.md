# 전체 댓글 재검토 결과

2,983개 전량의 원문과 답글 문맥을 2차로 읽고 의미별 주대상과 감성을 검토했다. 사람의 독립 검증은 시행하지 않았다. 기존 원문·ID·영상 구분·부모 관계를 유지했고, 이전 판정과 변경 사유를 별도 파일로 전달했다.

주대상은 댓글당 하나이며, 명시적인 최종 평가나 질문의 핵심 대상을 우선한다. 작품명·인물명 유무는 필수 조건이 아니다. 별명·오타·지시대명사도 문맥으로 해석한다. 여러 대상의 평가가 공존하면 혼합 감성을 보존하고 주대상은 가장 중심적인 대상을 정한다. 주대상 한 개만으로 복수 대상의 모든 의견을 표현하지 못하는 한계는 남는다.

## 의미별 주대상

- 작품·시리즈: 영화나 시리즈 전반의 평가, 관람 의사, 추천, 이탈, 시대·작품 비교.
- 배우·캐릭터: 배우의 연기·외모·캐스팅, 등장인물의 성격·능력·선호·등장 여부.
- 장면·서사·설정: 특정 장면, 사건, 줄거리, 설정의 설명·질문·추측·평가.
- 영상·제작자: 유튜브 편집·해설·목소리·광고·업로드·제작자에 대한 반응, 공지와 제작 요청.
- 홍보물·포스터: 공식 포스터·홍보 디자인·특전 포스터의 미감 평가.
- 상영·배급·관람환경: 상영관·시간·배급·OTT·예매·가격·특전 재고·관람 예절.
- 시청표시·시간정보: 본문 내용 없이 시간만 기재한 시청 표시. 시간표를 포함한 제작자 안내는 영상 대상으로 둔다.
- 기타·대화·대상불명: 잡담, 사람 사이의 대화·감사·공격, 홍보성 스팸, 의미 불명의 문자·반응. 의미를 판정하기 어려운 댓글을 억지로 작품 평가에 넣지 않는다.

## 감성

명확한 호평·만족·추천·기대는 긍정, 비판·실망·거부는 부정이다. 질문·정보·가설에는 중립을 사용한다. 감정 방향이 공존해 결론이 불명확하면 혼합, 해석할 수 없거나 방향이 불명확하면 판단 불가로 둔다. 인물의 죽음 때문에 슬프다는 표현만으로 작품을 부정으로 분류하지 않는다. 강한 비속어·은어도 문맥으로 해석하며 긍정 표현을 욕설이라는 이유만으로 부정으로 만들지 않는다.

## 사용자 지적 사례

- “진짜 몇년이 지났어도 희대의 명작” → 작품·시리즈 / 긍정.
- “성길이 대신 욘두가 살았으면 ㄹㅇ 1400만가지 다 이김” → 배우·캐릭터 / 긍정.
- “캅틴은 손녀와 키스했군…” → 장면·서사·설정 / 부정. 원문 표기는 그대로 유지한다.

이 세 댓글의 기존 AI 반응 대상은 이미 작품·캐릭터·장면으로 분류되어 있었으나, 별도로 생성한 키워드 태그가 기타로 남아 잘못된 발표용 집계가 되었다. 재검토에서는 이 둘을 혼용하지 않고 의미별 주대상으로 집계한다.

## 최신 모델 실험

학습 대상은 작품·캐릭터·장면·영상 대상의 명확한 긍정/부정으로 한정한다. 새로 분리한 포스터·상영환경은 제외한다. 라벨 정정 후 같은 후보 비교 절차를 다시 실행했다. 모델 종류와 설정을 성능 수치에 맞춰 튜닝하지 않았다. 데이터 필터와 분할이 달라졌으므로 이전 0.7143과 새 0.7969의 차이를 같은 조건의 개선으로 해석할 수 없다. 새 점수도 AI 참조 라벨과의 일치도이다.
